# Curso de Ruby

Repositório com os exercícios, anotações e o projeto final do curso gratuito de Ruby disponibilizado pela plataforma [OneBitCode](https://onebitcode.com/) através do YouTube.

📚 [Playlist do curso](https://youtube.com/playlist?list=PLdDT8if5attEOcQGPHLNIfnSFiJHhGDOZ)

## Conteúdo

### Fundamentos

- Variáveis, tipos de dados e `puts`/`print`/`gets`
- Estruturas condicionais (`if`/`else`) e laços de repetição
- Arrays e hashes
- Blocos e métodos de iteração, como `each` e `max_by`
- Métodos (definição, parâmetros e retorno)

### Orientação a Objetos (`POO`)

- Classes, objetos e `initialize`
- Variáveis de instância
- Módulos e namespaces (`Person::Juridic`)
- Métodos públicos, privados e protegidos

### Tópicos Avançados (`TopicosAvancados` e `TopicosAvancadosII`)

- Procs e lambdas
- Expressões regulares (regex)
- Módulos e herança

### Projeto Final (`Projeto_final`)

- **Leitura de arquivos**: `File.open` e leitura linha a linha
- **Chamadas web**: requisições `GET` e `POST` com `Net::HTTP` e HTTPS
- **Web scraping**: extração de dados de páginas HTML com Nokogiri
- **Gems**: uso de bibliotecas externas, como `cpf_cnpj`
- **Tradutor de textos**: programa em Ruby que traduz um texto entre idiomas usando uma API, tudo dentro de uma classe, e salva cada tradução em um arquivo com data e horário no nome

## Como executar

Com o [Ruby](https://www.ruby-lang.org/pt/downloads/) instalado, rode qualquer arquivo com:

```bash
ruby nome_do_arquivo.rb
```
